# Skills 设计

每个 Skill 文件夹保留标准的 `SKILL.md` 元数据和任务说明，并附必要的脚本与样例。

| Skill | 适用请求 | 输入 | 结果 |
|---|---|---|---|
| `comfyui-job-demo` | 准备工作流参数或验证任务调用方式 | 调用方节点图、绑定表、值 | 请求计划或任务状态 |
| `subtitle-timing-demo` | 给明确的 SRT 应用明确的时间偏移 | SRT、偏移量 | 文本不变的新 SRT |
| `trilingual-structure-demo` | 检查三行式中英拼音文本结构 | 已有三语文本 | 块级检查报告 |

这些说明从生产技能的职责与接口中提取，删除频道规则后重新编写。脚本提供独立的适配实现，不依赖原工作区或未公开文件。

关键约束包括：修改工作流副本而非输入模板；提交结果不确定时避免重复创建任务；字幕调整保留正文；结构检查通过不等于语言内容准确。

直接调用各 Skill 内脚本无需安装 Skill。如果要交给支持 `SKILL.md` 的助手使用，可选取单个文件夹放入对应环境的 Skill 目录。选择工作流和真实外部执行仍由具体任务授权决定。
